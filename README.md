# Sara Aduse Foundation Homepage

Entwurf anhand der Brand Guidelines vom Dezember 2025. Für Vercel: Projekt importieren, Framework 'Other' oder Vite wählen, Build `npm run build`, Output `dist`.

Die Bilder wurden aus der PDF-Bildwelt als Platzhalter extrahiert. Die Guidelines weisen darauf hin, dass KI-generierte Referenzbilder nicht für finale Anwendungen genutzt werden sollen. Vor Veröffentlichung bitte freigegebene Originalfotografien einsetzen.

Spendenbutton führt bewusst zu den in den Guidelines angegebenen Bankinformationen. Keine Zahlungsintegration vorhanden. Ein Link zur Datenschutzerklärung ist noch nicht hinterlegt. Die Wortmarke im Header ist typografisch gesetzt, da keine freigegebene separate Logo-Datei bereitgestellt wurde. Vor Veröffentlichung offizielles Logo einsetzen.
